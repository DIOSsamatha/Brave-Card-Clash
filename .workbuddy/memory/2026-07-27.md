## 30级精确经验系统 + 里程碑奖励

### progression_system.gd 大重构
- **新增 `LEVEL_XP_TABLE[31]`**: 精确累积经验表（0/300/600/.../44000），完全按策划案
- **新增 `LEVEL_MAX_HP[31]`**: 每级HP上限（40→70，Lv5/Lv10/Lv15等关键级+2HP）
- **新增 `Milestone` 枚举**: 13种里程碑（难度解锁/卡槽/技能等级/装备/商店/满级）
- **新增 `LEVEL_MILESTONES` 字典**: Lv5/10/15/20/25/30 各自的奖励列表
- **重写 `CharacterSave` 类**:
  - `_level_exp()` 动态公式 → `LEVEL_XP_TABLE[]` 查表
  - 新增 `exp_progress_ratio()` 经验百分比
  - 新增 `get_max_hp()` 等级HP查询
  - 新增 `get_skill_level()` 技能等级
  - 新增 `milestones_unlocked[]` + `has_milestone()`
- **重写 `add_exp()`**: 返回 `[levels_gained, milestones]` 支持连升多级+里程碑检测
- **新增静态方法**: `get_xp_for_level()`, `get_hp_for_level()`, `get_milestone_name()`
- **补漏**: `best_stage` 变量（game_state引用但未定义）

### character_data.gd 修改
- `get_health_bonus()`: 公式计算 → `ProgressionSystem.get_hp_for_level()` 查表
- `get_total_health()`: 直接返回查表值（不再加base max_health偏移）
- `get_damage_bonus()`: 微调（每级+0.02基础伤害，让高级角色更有力）

### battle_scene.gd 结算逻辑重写
- **胜利结算**（之前没有经验！）:
  - 新增 `_calculate_victory_reward()`: 基础30 + 层数×8 + 小局×3 + 敌人难度加成
  - 星尘 = 层数×3+5（比战败多）
  - 调用 `add_exp()` 获取升级信息，弹窗显示升级★和里程碑✦
- **战败结算增强**:
  - 同样通过新 `add_exp()` 返回值显示升级信息
  - 弹窗内容统一格式：经验/星尘/到达层数/升级/里程碑

### 关键设计决策
- 经验表为**累积制**：存的是总经验，升级时扣减
- HP完全查表：不再依赖公式，策划可精确控制每级数值
- 里程碑跟随角色存档：每个角色独立解锁（未来可扩展）
