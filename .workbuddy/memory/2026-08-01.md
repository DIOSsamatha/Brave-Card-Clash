## Boss战胜利后无法进入下一层幻境（修复）

### 现象
击败Boss（梅花精灵 HP:0/30）后，战斗界面卡死——操作按钮仍可见，无法进入下一层（水晶幻境）。

### 根因分析（防御性修复，多保险）
截图证据：Boss HP=0 但 要牌/停牌/加倍 按钮仍在 → `_on_battle_ended` 可能未触发或被覆盖。
核心链路：`_resolve_round()` → `enemy_health<=0` → `battle_ended.emit(true)` → `_on_battle_ended()` → 显示胜利弹窗 → 点"继续冒险" → `_continue_adventure()` → 检查 `is_boss_battle` → `current_round+=1` → 切地图

### 修复内容（2个文件）
1. **battle_scene.gd `_continue_adventure()`**：
   - 加双重Boss检测：主检查 `is_boss_battle` + Fallback通过敌人名称匹配（梅花精灵/方块巨人/红桃骑士/黑桃法师/近卫队长/黑桃魔王）
   - 加 `push_message` 输出推进日志便于调试
   - 清理 `_do_continue()` 中重复的 `_game_cleared/_defeated` 检查

2. **battle_scene.gd `_on_battle_ended()`**：
   - 加强注释说明强制隐藏操作控件的防御性

3. **map_scene.gd `_generate_new_map()`**：
   - 地图种子和层数索引直接读 `GameState.current_round`（不再依赖 `_current_layer` 时序）
   - 换层时自动清理过期 `map_visited` 记录（防止旧层数据污染新层节点可达性判断）

### 关键教训
- `_current_layer` 是地图场景内部缓存，在 `_refresh_all()` 才更新；而 `_generate_new_map()` 在 `_ready()` 中先调用 → 时序差导致生成地图用了旧层数
- 解决方案：数据源统一用 `GameState.current_round`（Autoload全局状态，始终最新）

## 加倍卡死修复

### 现象
点击加倍后界面卡死——只显示"加倍!"文字，操作按钮消失，无法继续

### 根因
`_on_double_pressed()` 无条件执行 `_hide_actions()` + 设置日志，但不检查 `player_action(DOUBLE)` 返回值。
当玩家牌数≠2（截图中有4张牌6♦8♠K♠K♣）时 `_player_double()` 返回 false，但按钮已被隐藏、状态已破坏 → 卡死

### 修复
`_on_double_pressed()` 加返回值检查：`var success: bool = _battle.player_action(DOUBLE); if not success: return`
失败时不动UI，游戏状态不受影响

## 角色选择界面43个错误修复（2026-08-01 傍晚）

### 现象
运行后 Godot 报 43 个错误，角色选择界面无法正常显示

### 错误清单与修复
1. 🔴 **`PanelContainer.add_theme_stylebox` 不存在** → tooltip 改用 `Panel`（不需要容器功能）
2. 🟡 **`layout_mode = 1` 枚举值无效** → 删除该行（用 anchor 时不需要 layout_mode）
3. 🟡 **变量名 `name` 遮蔽 Node 基类属性**（6处）→ 全部改用 `set_meta("internal_name", ...)`
4. 🟡 **整数除法警告** → Vector2 字面量加 `.0` 后缀，position 比较加 `float()` 转换

### 教训
- Godot 4 中 `PanelContainer` 的 stylebox 名是 `"panel_container"` 而非 `"panel"`；如果需要自定义 panel 样式直接用 `Panel`
- 动态创建节点时永远不要给变量命名为 `name`/`get_name` 等内置属性名
- GDScript 严格模式下整数除法会丢小数部分并报警告，浮点字面量必须带 `.0`
- **最安全的动态样式方案**：用 `Theme` 资源 `theme.set_stylebox("panel", "Panel", style)` + `node.theme = theme`，所有 Godot 4.x 版本兼容
