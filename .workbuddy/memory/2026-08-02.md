# 2026-08-02 工作日志

## Boss技能悬浮提示
- **需求**：战斗界面Boss信息栏的"技能: 梅花印记"标签，鼠标悬浮时显示具体技能介绍
- **实现**：在 `battle_scene.gd` 中新增敌人技能悬浮提示系统
  - 变量：`_skill_tooltip`(Panel) + `_skill_tooltip_label`(RichTextLabel)
  - `_create_skill_tooltip()`: 创建隐藏的金色边框深色面板，Theme资源设置样式
  - `_update_skill_tooltip_hover()`: 每帧在`_process()`中检测鼠标是否在`enemy_stance_label`区域
  - `_build_and_show_skill_tooltip()`: 构建BBCode内容（金色技能名 + 描述 + 触发概率）
  - `_position_skill_tooltip()`: 智能定位（优先上方→空间不够改下方→防超出屏幕）
- **数据来源**：`_current_enemy.special_desc`（技能描述）+ `special_trigger_chance`（触发概率）
- **样式**：深色半透明背景 + 金色边框 + BBCode富文本（与角色选择卡片tooltip风格一致）

## 法师技能2"诅咒爆牌"修复
- **问题**：使用"诅咒爆牌"后，庄家没有多抽牌
- **根因**：技能效果正确添加了 `FORCE_DRAW` 状态到 `enemy_status`，但 `battle_manager.gd` 的 `_deal_initial()` 和 `_dealer_play()` **从未检查该状态**
- **修复**：在 `battle_manager.gd` 中新增 `_apply_force_dealer_draw()` 方法：
  - 检查 `enemy_status` 的 `FORCE_DRAW` 状态
  - 按状态值（LV1=1张, LV2/LV3=2张）强制庄家额外抽牌
  - 抽牌后标记已消耗 + tick_rounds 减少持续回合
  - 发送 battle_log 通知："🔮 诅咒爆牌：庄家被迫抽取 [X♠]"
  - 在 `_deal_initial()` 末尾和 `_dealer_play()` 开头各调用一次
- **涉及文件**：battle_manager.gd（新增方法+两处调用点）

## 星尘持久化修复（启动时读档）
- **问题**：领取/获得星尘后关闭游戏，重新启动星尘数归零
- **根因**：`GameState._ready()` 只初始化了数据库（Enemy/Trump/Item），**从未调用 `SaveSystem.load_game()`**
  - 存档确实被正确写入磁盘（end_run/save_game 都调了）
  - 但内存中 `progression.star_dust` 永远是初始值 0
  - 主菜单 `_load_save_info()` 只是为了按钮显示文字而读JSON，没有恢复到 GameState
- **修复**：在 `GameState._ready()` 末尾加 `SaveSystem.load_game()` 调用
  - Autoload 最先初始化，保证所有场景读到时数据已就绪
  - 有存档则自动恢复星尘+升级等级+总冒险次数等全部永久进度
  - 无存档时静默跳过（首次运行）
- **涉及文件**：game_state.gd（_ready() 加3行）
