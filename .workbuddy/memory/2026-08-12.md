# 2026-08-12 主菜单设置"秒退"修复

## 问题
用户反馈：点击主界面"设置"按钮后游戏"秒退"；之前还反馈按钮位置歪、对应功能没实现、设置面板返回不了主界面。

## 根因分析
1. `scenes/main/main_menu.gd` 里用 `Control` 静态类型访问子类信号：`var panel: Control = ...; panel.closed.connect(...)`。在严格类型/Godot 4.7 环境下这会导致脚本解析失败，`_ready()` 中所有按钮信号连接都不会执行，按钮全部无响应。
2. 按钮各自用窗口锚点 + 固定偏移定位，在小分辨率/窗口缩小时可能重叠，导致点击区域错乱。
3. 设置面板返回按钮位置和层级不够准确，且背景 `TextureRect` 默认 `mouse_filter=Stop` 会拦截点击。

## 修复内容
- `scenes/ui/settings_panel.gd`：添加 `class_name SettingsPanel`，使主菜单能类型安全地引用信号。
- `scenes/main/main_menu.gd`：
  - `@onready` 路径改为 `$ButtonContainer/StartBtn` 等（按钮移入容器）。
  - `_on_settings()` 中实例化类型改为 `SettingsPanel`，连接 `panel.closed` 合法。
  - 增加 `_settings_open` 标记防止重复打开。
  - 面板打开后设 `z_index=100` 并 `move_to_front()` 保证在最上层。
- `scenes/main/main_menu.tscn`：
  - 新增 `ButtonContainer`（`VBoxContainer`），锚定在画面中心偏下（`0.5, 0.62`），尺寸 `320x260`。
  - 4 个按钮作为子节点移入容器，透明、大小 `320x50`、间距 `20`，永不重叠且与背景按钮框对齐。
- `scenes/ui/settings_panel.tscn`：
  - 返回按钮调大到 `140x55`，定位到右下角"返回"框区域。
  - 背景 `TextureRect` 设 `mouse_filter = 2`（Ignore），避免阻挡滑条和按钮点击。

## 后续 Parser Error 修复（同日下午）
- 用户截图：`main_menu.gd:104` 报 `Could not find type "SettingsPanel" in the current scope.`
- 根因：`main_menu.gd` 使用 `SettingsPanel` 类型名，但未通过 `preload` 加载声明该 `class_name` 的脚本；Godot 解析时找不到类型。
- 修复（第一轮）：`SETTINGS_PANEL_SCENE` 从运行时 `load(String)` 改为解析期 `preload(PackedScene)`，实例化时直接取该常量。
- 修复（第二轮）：仅 preload 场景仍不足以让 class_name 进入作用域，额外显式 preload 脚本本身：
  ```gdscript
  const _SettingsPanel: GDScript = preload("res://scenes/ui/settings_panel.gd")
  ```
  该常量虽不被直接引用，但会强制 Godot 在 `main_menu.gd` 解析时加载 `settings_panel.gd`，从而注册 `SettingsPanel` 全局类型。
- 修复（第三轮）：class_name 全局类型仍未被识别（可能因项目缓存或未完全重载）。为彻底绕过该解析问题，在 `main_menu.gd` 的 `_on_settings()` 中：
  - 不再使用 `SettingsPanel` 类型注解，改为 `Control`；
  - 信号连接改用字符串 `panel.connect("closed", _on_settings_closed)` 并前置 `has_signal("closed")` 检查。
  这样即使 `SettingsPanel` class_name 暂时无法解析，设置面板仍能正常实例化、显示和关闭。

## 对齐与点击问题修复（第三轮后续）
- 用户反馈：设置面板"返回"按不了；主菜单按钮按不到对应界面。
- 根因：透明 Button 的实际位置与背景图上的视觉按钮框对不上，用户点击的是背景图文字而非真正的 Button。
- 修复：
  - `scenes/main/main_menu.tscn`：
    - `Background` 设 `mouse_filter = 2`（Ignore），避免背景拦截点击。
    - `ButtonContainer` 锚点从 `(0.5, 0.62)` 下移到 `(0.5, 0.68)`，使透明按钮与背景四个按钮框对齐。
  - `scenes/ui/settings_panel.tscn`：
    - `BackBtn` 锚点从 `0.58~0.74 × 0.67~0.77` 扩大到 `0.55~0.80 × 0.68~0.82`，增大点击区域并覆盖右下角"返回"框。
  - `scenes/main/main_menu.gd` / `scenes/ui/settings_panel.gd`：在按钮回调里加 `print` 调试输出，便于确认点击是否被捕获。
