# 2026-08-20 地图改造：StS 式分支路线 + 路径锁定 + 拖动查看

## 需求
用户要求：地图按随机路线走、仅能走路线节点（类杀戮尖塔）、地图稍微加长、鼠标长按拖动查看地图。

## 改动（scenes/map/map_scene.gd）
- **地图加长**：`TOTAL_LAYERS` 6→7（起点 + 5 中间行 + Boss）。`LAYER_SPACING_X` 190→230，使内容宽于视口以支持拖动。
- **分支生成**：`_connect_rows` 每前驱节点连 1~2 个下游（保证出路 + 50% 概率额外分支），制造路线上的选择；相邻列约束使路线自然蜿蜒；每下游节点保证≥1入边。
- **路径锁定（核心）**：`_is_node_reachable` 改为仅返回"当前节点（`_current_node_id`）连接到的、未访问的、非起点"节点。选分支后只能沿该路线前进，其余分支变不可达（半透明不可点）。
- **当前节点持久化**：新增 `GameState.map_current_node_id`，点击节点时写入，地图重新生成（从战斗返回/换层）时恢复，保证路径位置不丢失。换层时重置为 -1。
- **拖动查看**：新增 `_map_content` 容器（子节点含节点+连线），`_map_area` 设 `clip_contents=true` 作裁剪视口。`_input` 实现左键长按拖动平移（8px 阈值区分点击/拖动，拖动结束后抑制误触节点 `_just_dragged`）；仅地图区域内可拖动，弹窗打开时不处理。
- **镜头跟随**：`_ensure_current_visible` 在每次 `_render_map` 后若当前节点超出视口则平移使其可见。
- 地图顶部加"🖱 按住左键拖动查看地图"提示（mouse_filter=Ignore 不挡点击）。

## 改动（scripts/autoload/game_state.gd）
- 新增 `var map_current_node_id: int = -1`，并在 `reset_adventure()` 中重置。

## 验证
- 需 Godot 编辑器内运行主菜单→开始冒险→地图，确认：① 分支路线随机；② 选节点后仅下游可点；③ 地图可拖动且当前节点在视野内；④ 战斗返回后路径位置保留。
- 已知边界：`_game_clear` 逻辑（行521/1405）依赖 current_round>=TOTAL_LAYERS，current_round 为 0-5 永不触发，实际通关由 Boss 战处理，保持原样。
